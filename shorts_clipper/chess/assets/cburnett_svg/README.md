# cburnett chess pieces

The SVGs in this directory are the **cburnett** piece set used by
[Lichess](https://lichess.org), by **Colin M.L. Burnett**.

- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- Source: <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett>

The PNGs in `../cburnett/` are rasterised from these SVGs at 256×256 and are
distributed under the same CC BY-SA 3.0 license. The rest of the project stays
under MIT; these assets keep their original license.
